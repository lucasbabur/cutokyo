## Delivered workflows

Agent tools now provide native document inspection, editing, removal, and independent installation into supported harnesses. Exact source scope, revisions, destination conflicts, recovery copies, supporting skill files, and unsupported portability reasons belong to the operation. Protected Cutokyo capture hooks link to native capture management instead of allowing arbitrary edits.

Settings permanently exposes native capture management after onboarding. It reuses per-harness preview, installation, verification, recovery, and removal without resetting saved selections, history, appearance, or onboarding. Removal changes configuration only. Already-loaded callbacks may remain active until their harness restarts. Configuration verification is not evidence of live capture.

Backup creation has a default private location, an optional new destination, a list of available copies, and actual completion details. Restore verifies the selected copy and current-history confirmation, retains a recovery backup, restores through SQLite's online backup API, and reloads history. Settings and harness configuration are outside this database backup's scope.

Session search supports literal terms, explicit phrases, relevance or newest sorting, exact counts and paging, retained-history facets, bounded matching-source previews, local-calendar Today, and preserved detail/back navigation. Browser ranking and Unicode tokenization are approximations. Native SQLite tests establish BM25 and unicode61 behavior.

The guardrails product was removed. Ordinary filesystem integrity, database recovery, local redaction, provider-egress consent, and plugin capability approval remain. Native provider analysis, proxy activation, and signed updates report their actual unavailable capabilities instead of claiming success.
